# Panduan untuk agen AI

Sebelum mengerjakan apa pun di repo ini, baca **[RENCANA-PENGEMBANGAN.md](RENCANA-PENGEMBANGAN.md)**.
File itu berisi konteks proyek, keputusan pemilik, tahapan, dan log progres.

- Setiap keputusan baru atau pekerjaan yang selesai wajib dicatat di file tersebut (bagian Keputusan, Tahapan, Log Progres).
- Tahap rancangan bukan izin implementasi: jangan ubah kode, database, atau konfigurasi untuk fitur yang masih
  berstatus rancangan sampai pemilik meminta secara eksplisit.
- Komunikasi dengan pemilik dalam Bahasa Indonesia, sederhana, formal, tanpa kata puitis.
