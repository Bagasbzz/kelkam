# ThesisFlow (MVP Phase 1)

A minimal, modern landing page with a waitlist for a SaaS tool that helps university students format their thesis automatically. 

**Tech Stack:** Next.js (App Router), Tailwind CSS (v4), Supabase, Lucide React.

## Project Structure

```text
thesis-flow/
├── public/                 # Static assets (images, icons)
├── src/
│   ├── app/
│   │   ├── globals.css     # Global styles and Tailwind configuration
│   │   ├── layout.tsx      # Root layout, fonts, and metadata
│   │   └── page.tsx        # Main landing page (UI layout)
│   ├── components/
│   │   └── WaitlistForm.tsx # Client component for the waitlist form
│   └── lib/
│       └── supabase.ts     # Supabase client initialization
├── .env.local              # Local environment variables (add your keys here)
├── package.json            # Project dependencies and scripts
└── ... (other standard Next.js config files)
```

## Running Locally

1. **Install Dependencies**
   If you just cloned the project, run:
   ```bash
   npm install
   ```

2. **Configure Supabase**
   - Create a project on [Supabase.com](https://supabase.com/).
   - Go to your Project Settings > API to find your URL and Anon Key.
   - Go to the SQL Editor and create a `waitlist` table:
     ```sql
     create table waitlist (
       id bigint generated by default as identity primary key,
       email text not null unique,
       created_at timestamp with time zone default timezone('utc'::text, now()) not null
     );
     ```
   - Setelah tabel dibuat, jalankan `scripts/supabase_migrations/005_secure_waitlist.sql`
     agar anonymous hanya dapat mendaftar dan tidak dapat membaca daftar email.
   - Update `.env.local` in the project root with your project credentials:
     ```env
     NEXT_PUBLIC_SUPABASE_URL=your-project-url
     NEXT_PUBLIC_SUPABASE_ANON_KEY=your-anon-key
     ```

3. **Start the Development Server**
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) in your browser.

## Deployment to Vercel

1. **Commit and Push to GitHub**
   Ensure your code is pushed to a GitHub repository.

2. **Deploy on Vercel**
   - Log into [Vercel](https://vercel.com/) and click **Add New > Project**.
   - Import your GitHub repository.
   - In the "Environment Variables" section, add:
     - `NEXT_PUBLIC_SUPABASE_URL`
     - `NEXT_PUBLIC_SUPABASE_ANON_KEY`
   - Click **Deploy**.

Vercel will automatically build the Next.js project and deploy your app.
