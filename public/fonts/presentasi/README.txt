Font presentasi keluhkampus
===========================

di bawah SIL Open Font License 1.1 (teks lengkap: OFL.txt). Font dipakai apa adanya (tidak diubah),
untuk pratinjau slide dan ditanam ke file PPTX hasil ekspor. Hak cipta tiap font milik perancangnya:
